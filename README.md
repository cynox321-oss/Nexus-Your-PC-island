# NEXUS 🚀
### Your PC. Your Island. Your AI.

NEXUS is an AI-powered desktop companion for Windows, designed to bring intelligent assistance and useful desktop utilities into one sleek, dynamic island interface.

## ✨ Features

- 🧠 AI-powered assistance
- 🎙️ Voice interaction
- 👀 Animated character with dynamic expressions
- 🏝️ Dynamic Island-style desktop interface
- ⏰ Clock and timer utilities
- 🎯 Focus mode
- 🖥️ Windows desktop integration

## 🛠️ Tech Stack

- Electron.js
- HTML5
- CSS3
- JavaScript
- Google Gemini API

## 💻 Platform

- Windows 11

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/cynox321-oss/Nexus-Your-PC-island.git
```

Navigate into the project:

```bash
cd Nexus-Your-PC-island
```

Install dependencies:

```bash
npm install
```

Start NEXUS:

```bash
npm start
```

## 🔐 Configuration

NEXUS may require an API key for AI functionality.

Store your API key securely in a local `.env` file. Never publish API keys or credentials.
